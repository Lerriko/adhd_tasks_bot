# Не потеряй

<img src="assets/avatar-v1.png" alt="Маскот: блокнот с заметкой" width="180">

Telegram-бот для мыслей и дел, которые легко потерять. Сохраняет сообщения, голосовые и скриншоты, помогает превратить их в задачи и возвращает к ним по напоминанию.

Учебный проект для портфолио, созданный с помощью OpenAI Codex. Код снабжён русскими комментариями. Без ИИ внутри бота и без распознавания речи или изображений.

**Стек:** Python · aiogram 3 · SQLite · asyncio · unittest.

## Пример использования

1. Отправить или переслать боту сообщение «Выйти из дома».
2. Сохранить как заметку либо нажать «Оформить сейчас» и ввести название задачи.
3. Назначить время дела — например, завтра в 14:30.
4. Выбрать напоминание за пять минут — в 14:25 — или указать своё время.
5. После выполнения убрать задачу в архив.

## Возможности первой версии

- Сохраняет собственный и пересланный текст, ссылки, голосовые и картинки с подписями во входящие.
- Позволяет оформить запись в задачу сейчас или напомнить о разборе через 30 минут.
- Хранит оригинальный текст или Telegram file_id голосового, позволяет открыть оригинал.
- Напоминает о задаче через 30 минут, час или 24 часа. Новое напоминание заменяет предыдущее.
- Разделяет время дела и время напоминания; поддерживает точную дату и варианты «за 5/15 минут».
- Предоставляет постоянное нижнее меню и настройку смещения UTC.
- Показывает входящие, задачи и архив страницами по пять записей.
- Хранит данные и ожидаемый ввод названия в SQLite, переживает перезапуск.
- Работает только в личной переписке с ботом; данные пользователей разделены.

## Запуск в Windows PowerShell

Python 3.10+ (локально проверяется на Python 3.14).

```powershell
# Открой PowerShell в папке скачанного или клонированного проекта.
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
```

В Telegram открой официального [@BotFather](https://t.me/BotFather), отправь `/newbot`, выбери имя и username. Вставь выданный токен после `BOT_TOKEN=` в локальном `.env`. Не публикуй токен и не присылай его в переписку. `.env` и база исключены из Git.

```powershell
.\.venv\Scripts\python bot.py
```

Открой созданного бота и нажми Start. Для остановки нажми Ctrl+C в терминале. Запускай только один экземпляр для одного токена.

## Проверка руками

1. Отправь текст и голосовое: обе записи появляются в `/inbox`.
2. Нажми «Оформить сейчас», введи название: запись появляется в `/tasks`.
3. Установи напоминание, затем заверши задачу: она появляется в `/archive`, напоминание отменено.
4. У заметки нажми «Через 30 минут», перезапусти бота: запись и напоминание сохранятся.
5. Нажми «Открыть оригинал» у голосового: бот отправит его снова.
6. Проверь с другого Telegram-аккаунта: его списки будут отдельными.

Автоматические проверки:

```powershell
.\.venv\Scripts\python -m unittest discover -v
```

## Как устроен код

- `bot.py`: сообщения и кнопки Telegram, карточки, фоновая проверка напоминаний.
- `storage.py`: таблицы SQLite и операции с записями.
- `scheduling.py`: преобразование местного времени в UTC и проверка дат.
- `test_bot.py`: сценарии диалога с подменёнными сетевыми запросами.
- `test_scheduling.py`: проверки дат и часовых смещений.
- `test_storage.py`: сохранность, разделение пользователей и жизненный цикл напоминаний.

Путь сообщения: Telegram → обработчик `save` → `Storage.add` → SQLite → ответ с кнопками.
У записи есть состояние `inbox`, `task` или `archive`. Напоминание содержит время UTC в Unix-формате и назначение: `review` (разобрать) или `task` (выполнить). Интервалы не зависят от часового пояса.

## Точная дата и местное время

У задачи теперь две независимые даты: «📅 Время дела» (`event_at`) и «🔔 Напомнить» (`due`). Например, выход 24.09.2026 в 14:30, уведомление в 14:25. Нажми «Время дела», введи дату и время, затем выбери «В момент дела», «За 5 минут», «За 15 минут» или «Своё время». Последний вариант позволяет указать любую будущую дату напоминания независимо от даты дела. «Без напоминания» сохраняет время дела. Прошедшее время напоминания не принимается. При переносе дела прежнее напоминание сохраняется до явного выбора нового варианта — бот сообщает об этом. После отправки уведомления время дела остаётся в карточке.

После `/start` под полем ввода появится постоянное меню: «📥 Входящие», «☑️ Задачи», «🗂 Архив», «⚙️ Настройки». Команды тоже продолжают работать. Переход в раздел отменяет незавершённый ввод названия или даты, сохраняя запись и ранее назначенное напоминание. Пересланный текст, совпавший с названием кнопки, сохраняется как заметка.

В `/settings` введи смещение от UTC: например, `+03:00` для Москвы, `+05:30` или `-04:00`. Это постоянное смещение, без автоматического перехода на летнее время. При сезонной смене времени настрой его вручную. Смена настройки меняет отображение уже назначенных напоминаний, но не момент их отправки.

У заметки нажми «Выбрать время разбора», у задачи — «Напомнить», затем «Своё время». Введи `ДД.ММ.ГГГГ ЧЧ:ММ`. Бот проверит дату и покажет результат в карточке. `/cancel` отменяет ввод и сохраняет предыдущее напоминание. Голосовые и пересланные сообщения во время ввода сохраняются отдельно.

Настройки и незавершённый ввод сохраняются в SQLite. Если местное время ещё не настроено, интервальные напоминания отображаются с явной пометкой UTC+00:00; при назначении точной даты бот сначала запросит смещение.

Обновление вступает в силу после перезапуска процесса. База обновляется автоматически добавлением таблиц, существующие записи остаются на месте. Если уже идёт проверка напоминания, сначала дождись его, затем останови процесс Ctrl+C и запусти той же командой. Не запускай второй экземпляр одновременно.

## Ограничения прототипа и следующие уроки

Напоминания отправляются только при работающем процессе и доступном интернете. После запуска бот отправит пропущенные напоминания. Проверка идёт каждые пять секунд. В редком случае сбоя после отправки, но до записи результата в SQLite, уведомление может повториться.

Голосовые и изображения не скачиваются на диск: хранится идентификатор файла Telegram. Картинки можно отправлять как фото или как файл с типом `image/*` (например PNG/JPEG без сжатия). «Открыть оригинал» возвращает сохранённый файл и подпись; для фото используется наибольшая доступная версия Telegram. Распознавания текста нет. Изображения из альбома сохраняются отдельными записями. Ссылка на исходный чат и атрибуция автора пока не сохраняются. Документы других типов (например PDF) пока не поддерживаются.

Следующие этапы: выбор даты кнопками календаря; часовые пояса с автоматическим летним временем; редактирование названия; поиск; удаление записей; постоянный запуск на сервере. SQLite подходит для учебного прототипа с небольшим количеством пользователей.

Первое упражнение: найти текст приветствия в `start`, изменить его, перезапустить бота и отправить `/start`. Затем разобрать вместе обработчик `save`.

Документация: [aiogram](https://docs.aiogram.dev/en/latest/), [Telegram Bot API](https://core.telegram.org/bots/api).
